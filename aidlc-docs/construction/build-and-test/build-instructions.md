# Build Instructions

## Prerequisites
- **Build Tool**: Vite v5 + TypeScript
- **Dependencies**: Node.js (v18+) and npm
- **System Requirements**: OS independent (Windows, macOS, Linux)

## Build Steps

### 1. Install Dependencies
```bash
npm install
```

### 2. Build All Units
```bash
npm run build
```

### 3. Verify Build Success
- **Expected Output**: Compiles client-side TypeScript cleanly and outputs bundled CSS/JS/HTML.
- **Build Artifacts**: Production bundle output inside `dist/` directory.
